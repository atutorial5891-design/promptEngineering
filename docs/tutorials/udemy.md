# Udemy

Udemy courses are paid, but they're usually discounted heavily during sales, so don't buy at list price. Ratings and "last updated" dates below were checked in October 2026. Check them again before you buy.

**Suggested order:** Bootcamp, then Agentic Track, then optionally Core Track. The bootcamp covers prompting breadth. The Agentic Track covers L4. The Core Track adds RAG and fine-tuning depth for modules 11 and 22.

## The Complete Prompt Engineering for AI Bootcamp (2026)

| | |
| --- | --- |
| **Instructors** | Mike Taylor and James Phoenix, authors of O'Reilly's *Prompt Engineering for Generative AI* |
| **Link** | [udemy.com/course/prompt-engineering-for-ai](https://www.udemy.com/course/prompt-engineering-for-ai/) |
| **Rating** | About 4.5-4.6, with 130k+ ratings |
| **Length** | About 22 hours, with 20+ projects |
| **Covers modules** | 02, 03, 04, 05, 06, 13, 15, 24, 25 |

- **Why:** this is the most widely taken prompt engineering course on Udemy. It's built around the "Five Principles of Prompting" and covers structured outputs (JSON and CSV), few-shot templates, production Python patterns, agents (OpenAI Agents SDK), and image and video generation.
- **Watch out for:** sections about specific products, like ChatGPT Agent Mode and Midjourney versions, go out of date fastest. Focus on the principles and the Python sections.

## AI Engineer Agentic Track: The Complete Agent & MCP Course

| | |
| --- | --- |
| **Instructor** | Ed Donner |
| **Link** | [udemy.com/course/the-complete-agentic-ai-engineering-course](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/) |
| **Rating** | 4.7, with about 47k ratings. Last updated 07/2026 |
| **Length** | A 6-week program with 8 projects |
| **Covers modules** | 14, 15, 16, 17, 23 |

- **Why:** a hands-on L4 course. It covers agent design patterns, the OpenAI Agents SDK, CrewAI, LangGraph, AutoGen, and a full week on MCP.
- **Watch out for:** it teaches several frameworks. Focus on the patterns, and compare them with [module 15](../modules/15-agent-patterns/index.md) and Anthropic's "Building effective agents".
