# Free Courses and Interactive Tutorials

## Anthropic Prompt Engineering Interactive Tutorial

- **Link:** [github.com/anthropics/prompt-eng-interactive-tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)
- **Format:** Jupyter notebooks with an example playground and an answer key. You need an API key.
- **Content:**
    - 9 chapters: basic structure, clarity, roles, separating data from instructions, output formatting and prefill, step-by-step thinking, examples, avoiding hallucinations, and complex prompts.
    - Appendices on chaining, tool use, and retrieval.
- **Covers modules:** 02, 03, 04, 05, 06, 07, 11, 14
- **Note:** it was written for Claude 3 Haiku, so the principles hold but some tips (prefill, explicit "think step by step") need adjusting for current reasoning models. See [module 09](../modules/09-reasoning-models/index.md).

## Anthropic Courses (the full set)

- **Link:** [github.com/anthropics/courses](https://github.com/anthropics/courses)
- **Content:** API fundamentals, the interactive prompt engineering tutorial, real-world prompting, **prompt evaluations**, and tool use.
- **Covers modules:** 02-07, 14, 18

## Microsoft: Generative AI for Beginners

- **Link:** [github.com/microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners)
- **Content:** 21 lessons. Lessons 04 (prompt engineering fundamentals) and 05 (advanced prompts) are the most relevant here. There's also a companion [AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) course.
- **Covers modules:** 01-04, 11, 15

## Hugging Face Agents Course

- **Link:** [huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course)
- **Content:** agent fundamentals (thought, action, observation), smolagents, LlamaIndex, LangGraph, agentic RAG, and a final benchmark project. It offers a free certificate.
- **Covers modules:** 14, 15, 17

## Learn Prompting

- **Link:** [learnprompting.org](https://learnprompting.org/)
- **Content:** a large, free, open course that runs from basics to advanced techniques and prompt hacking. Its team led *The Prompt Report*.
- **Covers modules:** 02-08, 20

## Prompt Engineering Guide (DAIR.AI)

- **Link:** [promptingguide.ai](https://www.promptingguide.ai/)
- **Content:** a reference-style guide to every named technique, with papers. It's best used as a lookup alongside the modules.
- **Covers modules:** 03, 06, 07, 08, 11, 15
